# Task Manager - Quản Lý Công Việc

## 1. Giới thiệu
Task Manager là dự án quản lý công việc cá nhân,
giúp người dùng dễ dàng theo dõi và sắp xếp các
công việc cần thực hiện hằng ngày.

## 2. Chức năng chính
- Thêm công việc mới.
- Chỉnh sửa thông tin công việc.
- Xóa công việc không cần thiết.
- Đánh dấu công việc đã hoàn thành.
- Theo dõi danh sách công việc.

## 3. Công nghệ dự kiến sử dụng
- HTML
- CSS
- JavaScript

## 4. Mục tiêu dự án
- Thực hành xây dựng một dự án phần mềm cơ bản.
- Tìm hiểu quy trình quản lý mã nguồn bằng GitHub.
- Rèn luyện kỹ năng lập trình và tổ chức dự án.

## 5. Đối tượng sử dụng
Sinh viên và những người muốn quản lý công việc
cá nhân một cách hiệu quả.
